# Beta 4：全球科属补查

验收日期：2026-09-07。应用版本：0.3.0-beta.4，Android versionCode 33。

## 实现与边界

旧版主要从百度百科摘要提取科属，摘要缺失或不符合提取格式就会漏项。新版将名称查询与照片识别分开：先保存已成功的识别，再补查分类。分类库超时不丢失识别结果，不重新消耗百度识图额度。

- iNaturalist：精确匹配学名、俗名、异名，读取祖先分类中的科、属和已命名杂交属。中文分类名可用时优先显示；否则显示拉丁名。
- GBIF / Catalogue of Life：结构化学名匹配，接受植物界的 EXACT 结果，不使用模糊匹配分数冒充准确率。
- Wikidata：核对完整标签、别名及 P225 学名，再通过 GBIF 校验植物分类。搜索摘要遗漏的别名也可参与查找。
- 园艺名称：支持带引号品种名、基础种、属、种下名称与杂交符号。仅匹配基础分类时明确提示品种尚未核实；不将跨属亲本公式截成第一个亲本。
- 同名记录只使用共同的科属；不同科属存在冲突时保留空项并提示补充学名。百度摘要给出明确学名时可用于消解俗名歧义。

打开观察记录会自动补查候选；项目页提供“补查已有记录科属”，人工复核页可按填写的名称重新查询。自动补查只更新候选及每张照片的候选，保留已确认字段、复核历史、版本号以及用户有意留空的字段。用户正在编辑的表单不被异步结果覆盖。

公共查询只发送植物名称或分类编号，不发送照片、位置、百度密钥。Android 使用固定 HTTPS 接口白名单，禁止任意 URL 和重定向。请求串行且至少间隔 1.05 秒；429 后该数据源冷却 60 秒。成功名称最多缓存 500 项、30 天；未查到/歧义缓存 10 分钟，网络异常只缓存 1 分钟。缓存存储失败不阻止查询。

## 覆盖率测量

固定样本在请求前写入 `apps/client/tests/taxonomy-live.mjs`，包含 100 个名称；失败项全部保留在分母。结果与源码 SHA-256 见 [完整实测数据](taxonomy/beta4-live.json)。

| 样本组 | 科、属均有值 | 总数 |
| --- | ---: | ---: |
| 中文常见植物名 | 27 | 30 |
| 全球学名（含蕨类、苔藓、裸子植物等） | 40 | 40 |
| 园艺及杂交名称 | 28 | 30 |
| 合计 | **95** | **100** |

这测量的是固定便利样本中“科、属字段均有值”的比例，**不是全球植物 99% 的覆盖证明，也不是照片识别或分类正确率**。没有随机抽样、独立分类专家盲审或用户真实照片识别评估；即使小样本达到 99%，也不能外推到全球植物和全部园艺商品名。

未补全的 5 个名称：

- 绣球、长寿花：完整别名查询发现不同科属的同名记录，需补充学名。长寿花的两条记录为 Kalanchoe blossfeldiana 与 Narcissus jonquilla，不能仅凭俗名强选一个。
- 兰花、多肉植物：当前名称查询未获得可唯一确定的科属。这类集合名称本身也不足以确定一个属。
- 无尽夏绣球：当前数据源未匹配到该完整商品名；补充基础学名后可查询。未编造属名以提高填充率。

银杏实测返回银杏科 / 银杏属；洋桔梗返回龙胆科 / 洋桔梗属，接受的学名为 Eustoma russellianum。Eustoma grandiflorum 的异名查询也通过。

第一轮仅检查搜索摘要时得到 93/100。补充完整别名和杂交属后得到 95/100，同时发现“绣球”的真实别名冲突并撤回原先单一匹配；不能只追求填充数量而忽略错误填充。

## 验证方法

- `npm run type-check`：通过。
- `npm test`：28 个用例通过，涵盖用户样例、别名、杂交属、园艺名称、模糊结果拒绝、缓存、异常及已确认字段保护。
- `npm run test:browser`、`npm run test:integration`、`npm run test:regressions`：通过。识别集成使用模拟百度响应，不消耗百度额度；切后台密钥草稿与错误框换行回归通过。
- `npm run test:taxonomy`：6 个浏览器流程通过，涵盖旧记录补查、输入期间保护、确认字段留空、离线保留、批量缓存复用，以及不将用户选择的“暂未确定”自动改成“确认名称”。
- `npm run test:taxonomy:live`：使用真实公开分类接口，100 名称、254 个实际请求；不上传照片或密钥。
- Android 原生百度回归通过（模拟 HTTPS），验证鉴权、撤销密钥、重试、令牌缓存、科属摘要传递和移除凭据；未消耗百度额度。
- Pixel 4 XL / Android 16 独立 QA 包实际查询银杏、洋桔梗通过，拒绝任意 URL 查询通过。检查期间出现过网络故障与 ADB 断连，联网恢复后查询通过；新增诊断日志捕获到 `SocketException: Software caused connection abort` 和 Wikidata 的 `UnknownHostException`。这些失败也计入验收记录，不能承诺公共网络一直可用。
- 发布包关闭调试，沿用之前的签名。测试不读取或改变主应用资料。
- 原生 UI 自动化期间曾遇到手机自动锁屏并进入 Dozing，影响网络和 WebView 帧回调。独立 QA 构建在前台保持屏幕亮起以完成测试；不修改手机全局休眠设置，发布包不包含此测试选项。

默认字号未改大。界面基准字体为 16px，标题为 2rem；发布包不包含测试时注入的放大样式。

## 数据源与限制

- [iNaturalist API](https://api.inaturalist.org/v1/docs/)、[API 使用建议](https://www.inaturalist.org/pages/api+recommended+practices)。只使用分类字段，不下载或分发接口中的图片。
- [GBIF Species API](https://techdocs.gbif.org/en/openapi/v1/species)、[分类解释文档](https://techdocs.gbif.org/en/data-processing/taxonomy-interpretation)。匹配使用 checklistKey `7ddf754f-d193-4cc9-b351-99906754a03b`。
- [Wikidata 数据访问说明](https://www.wikidata.org/wiki/Wikidata:Data_access)。结构化数据采用 CC0；只使用公开标签、别名和分类学名。

不同分类库可能采用不同的分类处理，尤其园艺杂交、旧属名及异名；每条自动结果保留来源、匹配证据、查询时间和拉丁科属名供复核。未建立完整离线全球名录；首次查询依赖网络，公共服务的可用性也会影响覆盖。当前 **99% 的要求尚未达到或验证**。
