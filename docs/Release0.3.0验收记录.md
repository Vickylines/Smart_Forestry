# v0.3.0 正式版验收

日期：2026-09-09。Android versionCode 34，最低 Android 10，包名 cn.zhihuilinye.preview。

## 本次变更

1. 设置页显示项目仓库完整地址，支持触屏和键盘激活。Android 原生桥只开放固定仓库地址；外部页面不会进入带有密钥、文件能力的本地 WebView。浏览器端新开页面并隔离 opener。没有可用的 Android 浏览器或处理程序时显示错误提示。
2. 重新补查明确无结果或存在歧义时，清除没有新证据支持的旧候选科属、学名与来源；断网保留旧值。每张照片的候选同步更新，不覆盖人工确认字段、历史和 revision。
3. 同株多图依次识别时，后续高分结果继承同名、同学名候选的最新分类信息；保留本次分数和照片归属，不借用其他名称的科属。
4. 移除采集照片时启用忙碌状态，防止文件清理完成前交叉发起采集。元数据仍先提交、再删除文件，存储提交失败不能先丢照片。

两个科属问题已通过新增测试在修改前复现失败，修改后通过。

## 验证结果

- `npm run type-check` 通过；`npm test` 共 30 项通过。
- `npm run build:h5` 通过，Android 分发包使用此生产输出。
- `npm run test:browser` 通过：项目、采集、复核、导出、删除、320/390/1100px 布局与 200% 字号。
- `npm run test:integration` 通过：模拟百度响应、逐图恢复、人工复核保护和 ZIP 原图完整性。
- `npm run test:regressions` 共 9 项通过：仓库浏览器跳转及旧桥提示、密钥草稿、错误框、存储异常、采集草稿恢复和跨项目待处理照片。
- `npm run test:taxonomy` 共 6 项通过：旧资料补查、用户编辑保护、已确认留空、暂未确定、离线手填及跨记录缓存。
- Pixel 4 XL / Android 16：QA 包从旧版本覆盖安装成功；仓库入口打开设备已安装的 GitHub App，原 WebView 留在设置页，返回后调查元数据一致。
- 同一设备 QA 原生鉴权测试通过：重复验证、失效凭据、重试、令牌缓存、分类摘要和移除密钥。使用模拟 HTTPS，不上传真实照片、不消耗百度额度。
- QA 前后台输入和 100% / 200% 字号检查通过；手机实际切换 HOME 后草稿仍保留，错误框无重叠。
- 分发 APK 版本、签名与内容检查通过；未包含 QA 测试类、测试密钥、私钥、环境文件、开发依赖或源映射，应用调试关闭。

照片删除回归曾在发起文件清理后立即重载页面，出现剩余孤立照片。现测试等待忙碌状态结束再重载；这验证正常完成路径，不能证明强制终止进程期间的跨存储原子性。元数据与照片分库存储，突然终止仍可能留下孤立文件，后续应增加可恢复清理机制。
