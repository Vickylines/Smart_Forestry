# 智慧林业 / Smart Forestry v0.3.0

## 简体中文

首个正式版，通过 GitHub Releases 分发，适用于 Android 10 及以上；未上架应用商店。

- 设置页新增“项目仓库”，显示完整地址，点击后由系统浏览器或 GitHub App 打开。返回应用可继续调查。
- 修复重新补查明确无匹配或存在歧义时，旧候选科属与来源残留的问题；网络暂时失败仍保留已知分类，人工复核结论保持不变。
- 修复同株后续照片得分更高时，已补全科属被覆盖的问题；保留新照片得分，只复用名称及学名相同的分类结果。
- 移除采集照片期间暂停其他采集操作，避免照片文件仍在清理时交叉操作。

安装 `zhihuilinye-0.3.0.apk`。沿用原包名及签名，versionCode 升至 34，可覆盖相同签名的旧版。建议升级前导出需要保存的资料；不用卸载旧版。附 `SHA256SUMS.txt` 供校验，不分发 inspection / QA 包。

类型检查、30 个单元测试、浏览器流程、9 项故障回归和 6 项分类库界面流程通过；Pixel 4 XL / Android 16 的独立 QA 包通过仓库跳转、前后台输入保持和原生鉴权回归。识别测试采用模拟响应，未消耗百度识别额度。发布 APK 已检查签名、版本、调试关闭和敏感内容。详见[验收记录](https://github.com/Vickylines/Smart_Forestry/blob/main/docs/Release0.3.0验收记录.md)。

资料仍仅保存在本机，暂无备份导入、云同步或多人协作。照片识别需配置个人百度密钥并人工复核。Beta 4 的固定 100 名称实测有 95 个返回完整科属，这是历史字段填充测量，不能作为照片识别准确率或全球覆盖保证。

## English

First stable release, distributed through GitHub Releases for Android 10+. This is not an app-store release.

- Adds a Settings repository link that opens in an external browser or GitHub app.
- Clears stale candidate taxonomy and source data when a fresh lookup definitively finds no match or an ambiguity. Temporary network failures retain known data; manual reviews are preserved.
- Retains enriched taxonomy when a later photo of the same plant has a higher score, without changing the new score or reusing taxonomy from a different name.
- Blocks overlapping capture actions while removing a photo.

Install `zhihuilinye-0.3.0.apk`. Package identity and signing certificate are unchanged; versionCode is 34. Compatible installations can update without uninstalling. Export important records before upgrading. A SHA-256 checksum is included; the QA APK is not distributed.

Type checking, 30 unit tests, browser workflows, 9 regression cases and 6 taxonomy UI flows passed. The isolated QA package also passed repository navigation, background/resume input retention and native authentication regression on Pixel 4 XL / Android 16. Identification responses were mocked; no Baidu identification quota was consumed.

Local-only storage remains; backup import, cloud sync and collaboration are not available. Identification requires personal Baidu credentials and manual review. The historical Beta 4 result of 95/100 names with complete family/genus fields is neither photo-identification accuracy nor a global coverage guarantee.
