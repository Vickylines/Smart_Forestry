# 智慧林业 / Smart Forestry · Beta 4

## 简体中文

新增全球科属名称补查，解决仅从百科摘要提取时银杏、洋桔梗等名称漏项的问题。识别后自动查询 iNaturalist、GBIF / Catalogue of Life，必要时用 Wikidata 别名连接学名；支持异名、园艺品种基础分类和已命名杂交属。

项目页可“补查已有记录科属”，不重新上传照片或消耗百度识图额度。人工复核可按输入的名称重查；后台补查保留已有人工结论和正在编辑的内容。网络故障保留识别结果，并支持稍后重试与本机缓存。继承 Beta 3 的密钥草稿与错误框修复，默认字号不变。

银杏、洋桔梗已通过真实接口验证。固定 100 名称实测 **95 个同时返回科、属**。这不是全球 99% 的覆盖承诺，也不是照片识别准确率；歧义、泛称和未收录商品名仍可能留空。品种只匹配到基础种或属时会明确提示，仍可手填。详见 [验收和完整样本](https://github.com/Vickylines/Smart_Forestry/blob/main/docs/Beta4验收记录.md)。

下载 `zhihuilinye-0.3.0-beta.4.apk`，适用于 Android 10+。可覆盖相同签名的旧版；建议先导出 ZIP 备份。照片识别需自行配置百度密钥，科属查询不需额外密钥，只发送名称，不发送照片或凭据。不要安装 inspection / QA 测试包。

## English

Adds global family/genus lookups using iNaturalist and GBIF / Catalogue of Life, with Wikidata aliases where needed. Supports scientific synonyms, cultivar base taxa and named hybrid genera. Ginkgo and lisianthus now resolve through structured taxonomy even when encyclopedia summaries are absent.

Existing observations can be enriched without uploading photos again or consuming Baidu identification quota. Review forms support explicit name lookup; automatic enrichment preserves confirmed fields and active edits. Includes caching and retry support. Beta 3 credential-draft and multiline-error fixes remain, with unchanged default font sizes.

In a fixed sample, **95 of 100 names returned both family and genus**. This is neither a global 99% coverage guarantee nor a photo-identification accuracy measurement. Ambiguous common names, broad categories and unlisted trade names can remain empty. Base-taxon matches do not verify a cultivar; manual editing remains available.

Install `zhihuilinye-0.3.0-beta.4.apk` on Android 10+. The APK uses the existing signing key and can update compatible earlier builds; export a ZIP backup first. Baidu credentials are required for photo identification. Public taxonomy requests send names only and require no additional key. Do not distribute or install the inspection / QA package as the regular app.
