## 中文

智慧林业 Beta 3 新增科属信息，修复密钥输入丢失和任务页错误提示错位。适用于 Android 10 及以上，同签名旧版本可覆盖安装。

### 新增与修复

- 新识别请求获取百度百科摘要，从明确的分类描述中补全科、属，并标注为待核对。缺失或有歧义时留空，可手动填写；旧记录没有摘要时需手填。
- 候选、人工复核、复核历史、项目列表与搜索支持科属。CSV 追加确认科、确认属和候选科属；ZIP 保留科属及候选依据。
- 输入 API Key 后切后台复制 Secret Key，返回时保留已填内容。保存失败也保留输入；成功保存、移除或页面卸载后清空。未保存的输入只在内存中，应用进程终止后不会恢复。
- 修复任务错误提示换行后边框拆开、与其他文字重叠的问题。支持窄屏和大字号，应用默认字号没有改大。

### 安装与验证

下载 `zhihuilinye-0.3.0-beta.3.apk`，使用 `SHA256SUMS.txt` 校验。APK 不包含百度密钥、QA 测试代码或调试开关。

已通过 16 项领域测试、7 组故障回归、浏览器流程、模拟识别集成和 4 项开发服务器测试。Pixel 4 XL / Android 16 的独立 QA 包已检查真实前后台切换、密钥草稿保留、科属预填及正常／两倍字号的错误框布局。原生模拟 HTTPS 测试验证了百科摘要参数和结果传递。

科属由百科摘要的保守文本规则提取，仍需人工复核；本轮未消耗真实识别额度，也未评测实际植物识别或科属补全准确率。完整范围见[验收记录](https://github.com/Vickylines/Smart_Forestry/blob/v0.3.0-beta.3/docs/Beta3%E9%AA%8C%E6%94%B6%E8%AE%B0%E5%BD%95.md)。

## English

Smart Forestry Beta 3 adds plant family/genus information and fixes disappearing credential input and broken task-error layouts. Requires Android 10 or later. Existing installations with the same signing certificate can be updated in place.

### Changes

- New identification requests include Baidu encyclopedia summaries. Explicit family/genus descriptions become suggestions marked for review. Missing or ambiguous values remain blank and can be entered manually. Older results without summaries require manual entry.
- Candidates, manual reviews, review history, project lists and search support family/genus. CSV adds confirmed family, confirmed genus and candidate taxonomy; ZIP preserves taxonomy and candidate evidence.
- Switching to another app to copy a Secret Key retains the API Key already entered. Failed saves retain both inputs. Successful saves, removal or page unload clear them. Unsaved inputs remain in memory only and do not survive process termination.
- Multiline task errors now wrap within one block without overlapping other text, including on narrow screens and with larger text. Default application font sizes are unchanged.

### Installation and validation

Download `zhihuilinye-0.3.0-beta.3.apk` and verify it using `SHA256SUMS.txt`. The APK excludes Baidu credentials and QA code; debugging is disabled.

Validation includes 16 domain tests, 7 failure-regression scenarios, browser workflows, simulated identification integration and 4 development-server tests. An isolated QA package on Pixel 4 XL / Android 16 verified real background/resume transitions, credential draft retention, taxonomy prefilling and task errors at normal/double text size. Mock HTTPS tests verified the encyclopedia request parameter and response forwarding.

Taxonomy suggestions use conservative text extraction and still require human review. No live recognition quota was consumed and no live identification or taxonomy accuracy benchmark was performed. See the [validation record](https://github.com/Vickylines/Smart_Forestry/blob/v0.3.0-beta.3/docs/Beta3%E9%AA%8C%E6%94%B6%E8%AE%B0%E5%BD%95.md).
