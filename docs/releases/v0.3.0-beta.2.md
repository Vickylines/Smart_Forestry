## 中文

智慧林业 Beta 2，修复照片草稿、存储故障和密钥验证问题。适用于 Android 10 及以上，可直接覆盖安装同签名的 Beta 1。

### 修复

- 连续拍照、打开相册或应用进程被回收后，已选照片可能失效或丢失。现在先持久保存照片草稿，保留备注与同株分组；提交观察成功后再清空草稿。
- 记录保存失败后，保留草稿以便重试。取消拍照不清除已有照片；移除草稿照片或删除项目时清理对应文件。
- 启动时存储写入失败不再让已有资料显示为空。升级暂时无法写入时仍可查看、导出；读取失败时禁止修改，避免覆盖旧资料。
- “验证密钥”每次重新请求鉴权，不再把缓存令牌视为密钥仍然有效的证明。调整连续请求的锁释放顺序和前端等待时间。
- 未保存的拍摄照片会返回所属项目处理，避免在另一项目误存或让拍照按钮无响应。

### 安装与验证

下载 `zhihuilinye-0.3.0-beta.2.apk`，可使用 `SHA256SUMS.txt` 校验。APK 不含百度密钥或 QA 测试代码，关闭应用与 WebView 调试。

已通过 14 项领域测试、5 组故障回归、浏览器流程回归和模拟识别集成。Pixel 4 XL / Android 16 真机通过连续拍照、取消拍照、强制重启、草稿恢复、保存失败重试与照片字节校验。原生鉴权回归使用模拟 HTTPS 响应，验证缓存、密钥失效及重试。

**测试边界：**本轮未使用有效百度密钥进行真实植物识别，也未评测准确率或剩余额度。验证密钥只检查鉴权。资料仍仅存本机；导出只包含已保存观察，请先保存需要备份的草稿。开发依赖审计告警仍保留，详见[验收记录](https://github.com/Vickylines/Smart_Forestry/blob/v0.3.0-beta.2/docs/Beta2%E9%AA%8C%E6%94%B6%E8%AE%B0%E5%BD%95.md)。

## English

Smart Forestry Beta 2 fixes photo drafts, storage failures, and credential verification. Requires Android 10 or later and supports updating a Beta 1 installation with the same signature. The app UI remains in Chinese.

### Fixes

- Selected photos could become unavailable after another capture, opening the gallery, or process loss. Photos are now persisted as local drafts together with notes and grouping; drafts are cleared only when observations are saved successfully.
- Failed record writes preserve drafts for retry. Cancelling the camera keeps existing photos. Removing a draft photo or deleting its project cleans up the corresponding files.
- A failed startup write no longer hides readable records. Failed migration writes preserve viewing and export; read failures block modifications to protect existing data.
- Verify key now performs fresh authentication instead of trusting a cached token. Native request lock release and the frontend response timeout have also been adjusted.
- Pending camera photos return to their original project, avoiding incorrect ownership or an unresponsive capture button in another project.

### Installation and validation

Download `zhihuilinye-0.3.0-beta.2.apk` and verify it with `SHA256SUMS.txt`. The APK contains no Baidu credentials or QA harness, and application/WebView debugging is disabled.

Validation includes 14 domain tests, 5 failure-regression scenarios, browser workflows, and simulated identification integration. Pixel 4 XL / Android 16 checks cover consecutive captures, camera cancellation, process restart, draft recovery, failed-save retry, and unchanged photo bytes. Native authentication regression uses mocked HTTPS responses to verify caching, revoked credentials, and retry.

**Test scope:** no live plant identification with valid Baidu credentials, accuracy benchmark, or quota check was performed. Verify key checks authentication only. Data remains local. Exports contain saved observations; submit drafts you want to back up first. Development dependency audit findings remain; see the [validation record](https://github.com/Vickylines/Smart_Forestry/blob/v0.3.0-beta.2/docs/Beta2%E9%AA%8C%E6%94%B6%E8%AE%B0%E5%BD%95.md).
