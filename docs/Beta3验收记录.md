# Beta 3 科属与界面修复验收

日期：2026-09-07（Asia/Taipei）。版本：0.3.0-beta.3，Android versionCode 32。[GitHub 测试版与安装包](https://github.com/Vickylines/Smart_Forestry/releases/tag/v0.3.0-beta.3)。

## 改动与边界

- 设置页原来的 `onHide(clearInputs)` 会在页面隐藏时清空未保存密钥。现在在同一次页面会话中保留输入，保存成功、移除成功或页面卸载后清空；保存失败保留输入供重试。输入草稿仅在内存中，未写入 localStorage、sessionStorage 或调查导出；已保存凭据仍由 Android Keystore / AES-GCM 加密。进程被系统终止或完全重启时，尚未保存的密钥草稿不会恢复。
- 任务页错误提示原为行内 `text`，窄屏换行会拆分边框并与上方文字重叠。已改为块级 `view`，公共错误样式支持长文本自动换行。
- 默认字号保持不变。大字截图仅用于 200% 字号回归检查；检查后已恢复正常字号。
- 候选、人工复核、复核历史和项目列表新增科、属；项目搜索支持科属。切换到缺少科属的候选时清空上一候选的字段；人工明确留空的已确认字段，重新打开时不会被候选回填。后续识别保留人工结论。
- CSV 保留原有列顺序，在末尾追加“确认科”“确认属”“候选科属”；ZIP 中的 CSV 和 JSON 包含科属、候选来源与复核历史。已有观察无需迁移或清除数据。

## 自动补全来源

[百度植物识别官方文档](https://ai.baidu.com/ai-doc/IMAGERECOGNITION/4k3bcxj1m)列出可选 `baike_num` 参数及 `baike_info.description`，没有独立的科、属字段。Android 直连与开发服务器现请求前五个候选的百科摘要，并保留摘要给客户端提取，不额外发起百科网页请求。

自动补全采用保守文本规则，仅提取与候选同名条目开头明确写出的中文科属；发现冲突、历史分类、比较、杂交或亚科／亚属等歧义时留空。来源标为“百度百科摘要 · 待核对”，提取依据与来源链接保留在候选数据及 ZIP 的 JSON 中。规则可能漏填，百科也可能采用不同分类体系，因此自动值仍须人工复核，不能视为权威分类数据库匹配。

只有新版新执行的识别会请求摘要；旧结果未保存摘要时不会凭名称猜测或自动重新提交照片，可手填科属。

## 验证

- 修改前新增回归复现：后台事件后 API Key 为空；320px 宽度下错误提示产生两个边框区域并与上文重叠。
- `npm run type-check` 和 `npm test`：16 项领域测试通过，覆盖科属缺失、歧义、来源、历史保留、人工清空和旧记录兼容。
- `npm run test:regressions`：7 组通过，新增密钥草稿前后台事件与切换标签页、保存失败／成功、Web 存储不含草稿，以及 320/390px、100%/150%/200% 字号的错误框边界检查。
- `npm run test:integration`：模拟原生桥接完成识别、自动科属预填、候选切换、人工修改与留空后重开、按科搜索、CSV/ZIP 导出及历史来源检查；原有离线采集、部分失败与重试用例通过。
- `npm run test:browser`：原有项目、采集、复核、设置、导出、删除及小屏／大字检查通过。
- `apps/recognition-server` 的 4 项测试通过，检查百科参数与摘要传递。
- H5 生产构建成功；Android 隔离 Inspection 包与分发包构建、签名校验及分发包归档检查通过。
- Pixel 4 XL / Android 16：隔离 QA 包真实 HOME / 回应用两次，先填 API Key、再填 Secret Key，输入均保留。原生任务错误框在 100% / 200% 字号下为完整单块且无重叠，科属候选能预填复核表单。
- 该 Pixel 的 WebView 在后台仍报告 `visibilityState=visible`；真机测试通过 Activity 状态验证切换，浏览器测试另行触发隐藏事件验证 `onHide` 路径，不将这两种证据混为一谈。
- 原生 `BaiduRegression` 在隔离 QA 包用模拟 HTTPS 验证百科参数及摘要传递，同时复验鉴权、失效密钥、重试和移除。未使用生产密钥，未消耗真实识别额度，未评测实际植物识别或科属补全准确率。

本地真机报告与截图在 `.preview/beta3/`；浏览器回归和集成报告在 `.preview/bugfix/` 与 `.preview/beta1/integration/`。这些测试资料不包含在 APK 中。分发包为 `dist/android/zhihuilinye-0.3.0-beta.3.apk`；真机验收使用独立 `.qa` 包，未覆盖安装用户主应用。
