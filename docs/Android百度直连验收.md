# Android 百度直连

2026-09-06 已构建并覆盖安装到 Pixel 4 XL，包名保持 cn.zhihuilinye.preview，安装未清除资料。

设置页新增百度 API Key、Secret Key 的保存、验证与移除。密钥使用 Android Keystore 的 AES-GCM 加密后存入应用私有存储，不写入 APK、网页存储或照片导出包。手机通过原生 HTTPS 直接调用百度，支持旧版 token 及新版 bce-v3 Bearer 两种方式，未禁用证书校验。

用户已提供旧版应用凭据，本机及手机原生鉴权均成功。账号调整后，2026-09-06 再次调用已获得正常识别响应，未再返回错误码 18。使用项目原创插图测试，百度返回“非植物”；客户端已过滤该项，不把它存为植物名称。完整手机流程已通过：采集页保存照片及备注、启动任务、原生直连百度、保存真实响应、重新加载后读取结果。测试通过文件输入事件提供图片，因此不代表系统相册或相机已验收，也不用于评估真实植物识别准确率。

客户端类型检查及 11 项领域测试通过。此前网页集成测试覆盖离线多图保存、备注、ZIP 原图校验、模拟接口断点继续及人工结论保留。实际相机拍摄、系统相册选图仍需补齐。ZIP 导出已成功打开手机系统保存窗口，但本轮未确认文件落盘，不能标记为完整通过。

直连是个人自用模式。已完成照片跳过；失败请求不自动重试。若百度完成计费但响应丢失，手动重试可能再次计费，直连未提供服务器幂等缓存。应用后台不保证持续执行。APK 仍为测试签名并开启 WebView 调试，正式发布前应关闭调试。

安装包：dist/android/zhihuilinye-0.2.0-test.apk。
后台方案代码保留作可选方案；已配置手机直连时无需启动电脑后台。
