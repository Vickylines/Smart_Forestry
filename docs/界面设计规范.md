**智慧林业 · 界面设计规范**

本轮依据 apple-design 技能及用户提出的“简约大方、说明简洁”调整。日期：2026-09-06。

**视觉与布局**

- 浅灰底、白色分组、森林绿主操作；首页优先呈现统计、项目与新建入口。
- 系统字体。页面标题约30–36px，正文15–16px，说明13–14px，状态12px。
- 页面两侧16–20px留白；桌面内容最大宽度880px。长名称允许换行。
- 控件圆角12–14px，内容分组18–22px。文字和状态共同表达信息。
- 按钮触控区至少44×44px，包括照片右上角的移除操作。
- 顶部和底部导航在H5支持轻微透明模糊；内容分组使用实色。

| 用途 | 色值 |

| 页面背景 | #F5F6F7 |
| 内容背景 | #FFFFFF |

**界面文案**

- 按钮直接写动作，如“新建项目”“选择照片”“保存观察”。
- 每处说明尽量一句话，紧邻相关操作；删除宣传句、重复标题和开发计划。
- 用“照片仅存本机，识别未接入。”说明当前边界。
- 待复核、已确认等状态保持可见；新版本不提供示例数据，评分不代表鉴定结论。
- 数据清理、导出不含照片等会影响用户决定的信息，放在设置页。

**交互与维护**

按钮按下立即反馈，松开确认；H5支持Enter和空格激活页面按钮，禁用项移出焦点顺序。进度使用transform更新，减少动态效果设置会关闭过渡；增强对比度和减少透明度时，导航采用实色。

公共样式在apps/client/src/App.vue，图标组件在components/AppIcon.vue。图标为本项目绘制的SVG；底部原生导航使用PNG。安装依赖并具备Chrome后，运行npm run generate:icons可重新生成。

H5将根字号固定为用户默认值100%，防止uni-app按屏宽缩小rem文字；几何尺寸采用px，文字采用rem。新组件若依赖rpx换算，应检查根字号策略。跨平台单位的支持范围参见[DCloud官方样式说明](https://uniapp.dcloud.net.cn/tutorial/syntax-css.html)。

浏览器检查覆盖六页、320/390/1100px、200%文字、触控尺寸与相关辅助设置。原生与微信小程序目前完成资源编译；系统字号、状态栏、触控和读屏行为仍需真机验收。
